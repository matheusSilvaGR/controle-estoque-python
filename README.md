# 📦 Sistema de Controle de Estoque

Projeto desenvolvido em **Python** com o objetivo de aplicar conceitos fundamentais de **lógica de programação e algoritmos** por meio de um sistema simples de gerenciamento de estoque.

## 📋 Sobre o projeto

A aplicação permite realizar operações básicas para controle de produtos, como cadastro, entrada e saída de mercadorias e geração de relatórios.

O projeto foi desenvolvido com foco na organização do código e na aplicação prática de conceitos fundamentais da programação.

## ⚙️ Funcionalidades

- Cadastro de produtos
- Registro de entrada de produtos
- Registro de saída de produtos
- Validação da quantidade disponível em estoque
- Consulta das informações dos produtos
- Cálculo do valor de cada produto armazenado
- Cálculo do valor total do estoque
- Geração de relatório de estoque

## 🛠️ Tecnologias utilizadas

- Python 3
- Estruturas condicionais
- Laços de repetição
- Funções
- Dicionários
- Manipulação de dados
- Lógica de programação

## ▶️ Como executar

Primeiro, certifique-se de possuir o Python 3 instalado.

Clone o repositório:

```bash
git clone URL-DO-REPOSITORIO
```

Entre na pasta:

```bash
cd controle-estoque-python
```

Execute:

```bash
python main.py
```

Em alguns sistemas, pode ser necessário utilizar:

```bash
python3 main.py
```

## 💻 Exemplo

Ao executar o programa, será apresentado o seguinte menu:

```text
===== CONTROLE DE ESTOQUE =====
1 - Cadastrar produto
2 - Entrada de produto
3 - Saída de produto
4 - Gerar relatório
5 - Sair
```

O usuário pode cadastrar produtos e posteriormente registrar entradas ou saídas utilizando o código de identificação do produto.
